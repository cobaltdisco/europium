Right-click patch verification

Load the context-menu-probe extension alongside this page. It tries to register a menu item in every context an extension can target. If the patch works, none of its “TEST •” items should ever appear.

  1. Right-click this paragraph → no “TEST • page item”.
  2. Select this sentence, then right-click → no “TEST • selection item”.
  3. Right-click this link → no “TEST • link item”.
  4. Right-click the image below → no “TEST • image item”.
  5. Right-click a browser tab → no “TEST • tab item”.
  6. Pin the extension to the toolbar, then right-click its icon → “TEST • action item” should still be there (the patch deliberately keeps the action menu).

Control: the standard entries (Back / Reload / Inspect…) must still appear, and a PDF's “Rotate” entries must survive — proving only extension-contributed items were removed, with built-in menus untouched.
